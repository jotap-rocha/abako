# sisfin

Sistema financeiro pessoal: controle de saldos por banco/conta, gastos e situação do orçamento mensal (apertado ou folgado).

## Arquitetura (planejada)

- **Frontend**: React + TypeScript (PWA)
- **Backend**: API FastAPI + PostgreSQL
- **Automações**: rotinas em segundo plano (importação, conferência, alertas)

> Projeto em fase inicial. O nome `sisfin` é provisório.
